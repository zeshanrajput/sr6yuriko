Network Benefits

  • Edge Storage: Capacity 12 (SUB 7 Transcendent Network, 5 M-TOC II).
  • -6 Noise Reduction: Designer home device -2, signal scrubber -2, ECM warrior -2.
  • +1 Sensor Rating: Added to any connected sensor (sensor upgrade).
  • Resonant Coordination: Connected characters using Send Message (Minor Action) among themselves gain a bonus Minor Action immediately.
  • Smartsoft Array:
    • Drone Sensor Locks shared among networked drones.
    • Target Locked victims cannot spend Edge against attacking networked drones.
  • Detect Ambush: -2 Perception test threshold to detect ambush.
  • Smartguns: +1 AR to smartlinked weapons.
  • Encryption: +1 threshold for all incoming Cracking tests against network.
  • Tactical Software Apps:
    • Artillery Barrage: +1 to Launchers, no rifle/mg/cannon penalties.
    • ECM Warrior II: +2 Offensive Cracking tests.
    • Sneak-Sneak: +2 Stealth.
    • Target Artist: Attack without LOS on painted targets.

Home Device & Remote Network Protocols

1. Home Device Configuration (Active Venue Drone)

  • Venue Drone as Home Device: Reiko configures her active inhabited drone (Shiawase Butler or Man-at-Arms) as her Home Device instead of the M-TOC II.
  • Sprite Power ‘Override’: Replaces active drone’s Pilot rating with her Resonance (8).
  • Attribute Enhancement: Adds +1 to Body (or Sensors).
  • Designer Trait / AI Origin Benefits: +1 Pilot/DP, +2 Noise Reduction, Edge Defense Rating considered 4 higher [HnS p. 124].

2. Remote Node & Seattle Retrans Setup

  • Seattle Relay Node: Federated-Boeing Sky Commander drone hosts heavy digital assets (M-TOC II, software tags, Sanctuary Host).
  • Drone Upgrades: Satellite Link, Retrans Unit (cleans Matrix noise), RAM Plating 4, Enhanced Sensors 3, ECM 6, Integrated Matrix Docks.
  • Framework Host Specs (Reiko’s Apartment):
    • Rating 2, Scale 1 (Micro/Personal LAN), Grade 2.
    • ASDF: Attack 2, Sleaze 2, Data Processing 3, Firewall 3 [HnS p. 154].
    • Defense: Patrol IC, Acid IC budget.
    • Foundation Door: Quartz sliding glass door framed in gold logic/indigo circuits leading directly into the Deep Matrix Kernel Panic glade.
