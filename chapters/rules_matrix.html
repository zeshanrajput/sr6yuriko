Matrix & Network Protocols

This reference details Reiko’s Matrix attributes, action pool breakdowns, network benefits, learned programs, defense math, remote node network architecture, and decking cheat sheet.

Note on Augmented ASDF Limits: Under SR6 AI rules (Hack & Slash pp. 116–120), Matrix ASDF attributes represent the intrinsic physical and mental characteristics of Artificial Intelligences (AI) and Emergent Intelligences (EI), making them subject to the standard +4 Augmented Attribute Limit. Unlike metahuman deckers (who use cyberdeck hardware arrays) or metahuman technomancers (who derive persona stats from mental attributes and can exceed +4 via complex forms), an AI/EI’s ASDF is capped at +4 above natural base scores.

Home Device & Remote Network Protocols

1. Home Device Configuration (Active Venue Drone)

  • Venue Drone as Home Device: Reiko configures her active inhabited drone (Shiawase Butler or Man-at-Arms) as her Home Device instead of the M-TOC II.
  • Sprite Power ‘Override’: Replaces active drone’s Pilot rating with her Resonance (8).
  • Attribute Enhancement: Adds +1 to Body (or Sensors).
  • Designer Trait / AI Origin Benefits: +1 Pilot/DP, +2 Noise Reduction, Edge Defense Rating considered 4 higher [HnS p. 124].

2. Remote Node & Seattle Retrans Setup

  • Seattle Relay Node: Federated-Boeing Sky Commander drone hosts heavy digital assets (M-TOC II, software tags, Sanctuary Host).
  • Drone Upgrades: Satellite Link, Retrans Unit (cleans Matrix noise), RAM Plating 4, Enhanced Sensors 3, ECM 6, Integrated Matrix Docks.
  • Framework Host Specs (Reiko’s Apartment):
    • Rating 2, Scale 1 (Micro/Personal LAN), Grade 2.
    • ASDF: Attack 2, Sleaze 3, Data Processing 4, Firewall 5 [HnS p. 154].
    • Defense: Patrol IC, Acid IC budget.
    • Foundation Door: Quartz sliding glass door framed in gold logic/indigo circuits leading directly into the Deep Matrix Kernel Panic glade.

2. Electronics Tests (Electronics + RES)

  • Software Specialization: Control Device, Format Device, Jack Out, Jump into Rigged Device, Reboot Device, Set Data Bomb, Trace Icon.
  • Computer Specialization: Edit File, Encrypt File, Erase Matrix Signature, Hash Check, Matrix Perception, Matrix Search, Modify Icon, Threat Analysis.
  • Hardware Specialization: Denial of Service, Squelch, Subvert Infrastructure, Turning off Wireless, removing headjammer, keycard copier, tag eraser, bug scanner.
  • Complex Forms: Any complex form requiring an Electronics test.

3. Matrix Edge Actions

  • 1 Edge: Batch Exec, Emergency Boost, Paint Target.
  • 2 Edge: Technobabble (CHA instead of LOG), Intervene, Hog, Signal Scream.
  • 3 Edge: Under the Radar (Action does not increase OS).

Foundation Rules

Base Foundation Rules

[HnS p. 141]

  • Social Tests: Cracking [Hacking]
  • Perception/Physical/Piloting: Electronics [Computer]
  • Combat: Cracking [Cybercombat]
  • Technical tests: Electronics [Software] or Cracking [Electronic Warfare]
  • Physical Attributes follow the Matrix Equivalent Attributes
  • All damage is 3P or 3S

Nexus Protocol Rules

[HnS p. 142]

  • Characters with an Electronics or Cracking skill also gain a pool of bonus dice to use. This pool is equal to the higher skill rating and refreshes each combat round. Outside of combat, a maximum of half the pool can be added to a test.
  • Hitchhikers gain +1 to their highest-rating skill and attribute.
